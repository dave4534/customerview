# Customer View (prototype)

Interactive prototype of the Fiverr "Customer View" admin redesign.

- Local with a real API: `node server.js` (port 3001 with `PORT=3001`), data in `data/db.json`.
- Hosted (Vercel): static files from `public/`. With no API available it falls back to an in-browser store (localStorage); use the app's data reset by clearing site data.
